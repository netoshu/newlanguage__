# PadMotion

A controller-driven motion graphics instrument: physical gestures become visual expression.

## Run as a desktop app

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm start`.
4. Connect a standard-mapped game controller, or use the keyboard controls shown in the app.

The embroidery/cross-stitch look is intentionally kept intact. The gradient look now uses a shared family of luminous multi-stop gradients, soft chromatic atmosphere, glow, and subtle grain so individual emotions can vary without feeling like unrelated visual styles.

## Controls

The in-app control guide lists gamepad and keyboard mappings. Recording stores timestamped input samples at 60 Hz; replay uses that captured input log.
